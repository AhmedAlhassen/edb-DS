Standards for building Sudanese banking interfaces that handle dual script systems, local currency formatting (SDG), and RTL layout transitions for the Export Development Bank.

Currency & Numbers

Formatting rules for Sudanese Pounds (SDG). EDB uses Arabic-Indic digits (٠١٢٣) for consumer-facing RTL views and Western digits (0123) for technical or LTR dashboards.

Context Western Digits Arabic-Indic Digits
Transaction Amount 1,250.50 SDG ١,٢٥٠.٥٠ ج.س
Account Number 002-123456-01 ٠٠٢-١٢٣٤٥٦-٠١
info

Rule: Always align decimals vertically in banking tables regardless of the digit system used.
