Iconography & Engineering Handover

This document outlines the technical standards for iconography and the transition strategy from Figma design tokens to our production React component library.

grid_view

Iconography Guidelines

Visual Standards

payments 24px

Grid & Clear Space

All icons must be designed on a 24x24px grid with a 2px safety padding (Safe Zone) on all sides to prevent optical clipping.

1.5px / 2.0px

Stroke Weight

Default stroke weight is 1.5pt. For emphasized actions or high-density screens, use 2.0pt. Avoid decimal weights to prevent anti-aliasing blur.

RTL & Mirroring Rules

Given the Sudan context, certain icons must flip for RTL layouts while others remain static.

Never Mirror
credit_card
lock
camera_alt

Static objects, logos, and credit cards.

Always Mirror

Tailwind Token Strategy

  theme: {
    extend: {

          dark: 'var(--background-dark)'

      spacing: {
        'safe-x': 'clamp(1rem, 5vw, 2rem)',
        'safe-y': 'clamp(1rem, 5vh, 2rem)'

      }
    }
  }

info Quick Start Guide

  1. Initialize the repository using npm install
  2. Export design tokens from Figma using the Tokens Studio plugin
  3. Run npm run build:tokens to generate CSS variables
  4. Start the storybook environment with npm run storybook
  5. Follow the PR template for every new component addition
