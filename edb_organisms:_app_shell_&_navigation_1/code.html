Bi-directional Parity (RTL/LTR)

Every component in the EDB App Shell is built with CSS Logical Properties. When the `dir="rtl"` attribute is present on the `` or `` tag, the Drawer automatically anchors to the right, icon orientations (like chevrons) mirror, and text alignment shifts seamlessly to support Arabic language requirements.
